# বিক্রমপুর মিষ্টান্ন ভান্ডার — Website

vmb-bd.com এর নতুন পাবলিক ওয়েবসাইট (তথ্যমূলক — হোম, মিষ্টি, ব্রাঞ্চ, আমাদের কথা)। এই মুহূর্তে সম্পূর্ণ স্ট্যাটিক (HTML/CSS/JS), কোনো ব্যাকএন্ড/ডাটাবেজ লাগে না।

## লোকালি চালানো

```
npx serve . -l 4173
```

তারপর ব্রাউজারে খুলুন: http://localhost:4173

## স্ট্রাকচার

- `index.html` — হোম পেজ
- `sweets.html` — মিষ্টির তালিকা (ক্যাটাগরি ফিল্টার সহ)
- `branches.html` — সব ব্রাঞ্চ (সার্চ সহ, ডাটা: `assets/js/branches-data.js`)
- `about.html` — আমাদের কথা, যোগাযোগ
- `assets/css/site.css` — শেয়ার্ড স্টাইল
- `assets/js/` — শেয়ার্ড স্ক্রিপ্ট ও ব্রাঞ্চ ডাটা
- `assets/img/` — লোগো ও প্রোডাক্ট ছবি
